Feature Engineering Techniques for Machine Learning

Introduction

Feature engineering is the process of creating new features from raw data to improve model performance. Good features can make simple models work better than complex models with poor features.

1. Numerical Feature Engineering

1.1 Binning

Convert continuous variables into categorical bins.

Example: Age binning

Age ranges: 0-18 (child), 19-35 (young adult), 36-60 (middle age), 60+ (senior)

Advantages: Reduces impact of outliers, captures non-linear relationships

Disadvantages: Loss of information, arbitrary bin boundaries

1.2 Scaling and Normalization

Transform features to similar ranges.

Min-Max Scaling: Scales to range [0, 1]

Formula: (X - X_min) / (X_max - X_min)

Use case: Neural networks, image processing

Standardization: Scales to mean=0, std=1

Formula: (X - mean) / std

Use case: SVM, Linear Regression, PCA

1.3 Log Transformation

Apply logarithm to reduce skewness.

Use case: Right-skewed data (income, population)

Formula: log(X + 1) to handle zeros

Effect: Makes distribution more normal

1.4 Polynomial Features

Create interaction terms and higher-degree features.

Example: For features [a, b]

Degree 2: [a, b, a^2, ab, b^2]

Degree 3: [a, b, a^2, ab, b^2, a^3, a^2b, ab^2, b^3]

Caution: Increases dimensionality exponentially

2. Categorical Feature Engineering

2.1 One-Hot Encoding

Create binary column for each category.

Example: Color [Red, Blue, Green]

Becomes: Color_Red [1,0,0], Color_Blue [0,1,0], Color_Green [0,0,1]

Advantages: No ordinal assumption

Disadvantages: High dimensionality with many categories

2.2 Label Encoding

Assign integer to each category.

Example: Size [Small, Medium, Large]

Becomes: [0, 1, 2]

Use for: Ordinal variables with natural order

Caution: Do not use for nominal variables in linear models

2.3 Frequency Encoding

Replace category with its frequency.

Example: City [NYC, LA, NYC, Chicago, LA, LA]

NYC appears 2 times, LA appears 3 times, Chicago appears 1 time

Becomes: [2, 3, 2, 1, 3, 3]

Advantage: Preserves information about category importance

2.4 Target Encoding

Replace category with mean of target variable.

Example: City vs Average_Price

NYC: 500K, LA: 800K, Chicago: 400K

Replace: [NYC, LA, Chicago] with [500, 800, 400]

Caution: Risk of data leakage, use with cross-validation

3. DateTime Feature Engineering

3.1 Extract Components

Year, Month, Day, Hour, Minute, Day of Week, Quarter

Is_Weekend (binary: 0 or 1)

Is_Holiday (binary: 0 or 1)

3.2 Time Since Event

Days since last purchase

Hours since registration

Months since previous login

3.3 Cyclical Encoding

For features like hour, month, day_of_week that are cyclical.

Formula for hour:

hour_sin = sin(2 * pi * hour / 24)

hour_cos = cos(2 * pi * hour / 24)

4. Text Feature Engineering

4.1 Bag of Words

Count frequency of each word in document.

Example: "machine learning is great, machine learning is fun"

Features: {machine: 2, learning: 2, is: 2, great: 1, fun: 1}

4.2 TF-IDF

Term Frequency - Inverse Document Frequency

Weights words by importance across documents.

Formula: TF-IDF = (word count in document) × log(total documents / documents containing word)

4.3 Word Embeddings

Represent words as dense vectors (Word2Vec, GloVe)

Dimension: Typically 50, 100, 200, or 300

Advantage: Captures semantic relationships

5. Domain-Specific Features

5.1 Ratio Features

Create ratios between related features.

Examples:

Price per square foot = Price / Area

Debt-to-income ratio = Total_Debt / Annual_Income

Click-through rate = Clicks / Impressions

5.2 Aggregation Features

Group by category and calculate statistics.

Examples:

Average purchase by customer

Total sales by region

Standard deviation of prices by category

5.3 Lag Features (Time Series)

Use previous time period values as features.

Examples:

Sales_lag_1 = Sales from previous day

Sales_lag_7 = Sales from 7 days ago

Rolling_mean_7 = Average sales over last 7 days

6. Feature Selection

After creating features, select the most important ones.

6.1 Filter Methods

Correlation with target

Chi-square test for categorical features

ANOVA F-test for numerical features

6.2 Wrapper Methods

Recursive Feature Elimination (RFE)

Forward selection

Backward elimination

6.3 Embedded Methods

L1 Regularization (Lasso) - zeros out coefficients

Tree-based feature importance

Coefficients from linear models

Best Practices:

Start with domain knowledge

Create features that capture business logic

Avoid data leakage

Test feature importance

Remove highly correlated features

Document all feature transformations

Use feature engineering pipelines for reproducibility
