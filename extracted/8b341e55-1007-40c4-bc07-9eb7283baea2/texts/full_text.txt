Spam Email Detection Project

Project Overview
This project implements a spam email classifier using Natural Language Processing and Machine Learning techniques.

Dataset
Total emails: 5,572
Spam emails: 1,368 (24.5%)
Ham (non-spam) emails: 4,204 (75.5%)

Methodology

1. Data Preprocessing
Text cleaning and normalization
Removal of special characters
Tokenization

2. Feature Engineering
TF-IDF vectorization
n-gram features (unigrams and bigrams)
Feature dimension: 5,000

3. Model Training
Algorithm: Naive Bayes Classifier
Train-test split: 80-20
Cross-validation: 5-fold

Results
Training Accuracy: 98.2%
Test Accuracy: 96.7%
Precision: 94.5%
Recall: 92.3%
F1-Score: 93.4%

Key Findings
Most important features: "free", "winner", "click", "urgent"
False positive rate: 3.2%
False negative rate: 4.8%
Average prediction time: 0.003 seconds

Conclusions
The Naive Bayes classifier performed exceptionally well for spam detection, achieving 96.7% accuracy with fast inference time.
