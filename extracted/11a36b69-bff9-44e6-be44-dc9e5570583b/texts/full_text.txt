Deep Learning Basics

Neural Networks Architecture

Perceptron (Single Neuron)
Components:
Inputs: x1, x2, ..., xn
Weights: w1, w2, ..., wn
Bias: b
Activation function: f

Output: y = f(sum of weighted inputs plus bias)

Multi-Layer Perceptron (MLP)
Structure:
1. Input layer: Receives features
2. Hidden layers: Process information (1 or more layers)
3. Output layer: Produces predictions

Forward Propagation:
1. Multiply inputs by weights
2. Add bias
3. Apply activation function
4. Repeat for each layer

Activation Functions

Sigmoid:
Formula: sigma(x) = 1 divided by (1 plus e to the negative x)
Range: 0 to 1
Use: Binary classification output layer
Problem: Vanishing gradient

Tanh:
Formula: tanh(x) = (e to the x minus e to the negative x) divided by (e to the x plus e to the negative x)
Range: negative 1 to 1
Use: Hidden layers (better than sigmoid)
Problem: Vanishing gradient

ReLU (Rectified Linear Unit):
Formula: f(x) = max(0, x)
Range: 0 to infinity
Use: Most common for hidden layers
Pros: Fast computation, no vanishing gradient
Cons: Dead neurons (Dying ReLU problem)

Leaky ReLU:
Formula: f(x) = max(0.01x, x)
Range: negative infinity to infinity
Use: Fixes dying ReLU problem
Advantage: Never truly dead

Softmax:
Formula: sigma(x)i = e to the xi divided by sum of e to the xj
Range: 0 to 1, sums to 1
Use: Multi-class classification output layer
Produces: Probability distribution

Training Neural Networks

Loss Functions

For Regression:
Mean Squared Error (MSE): Average of squared differences
Mean Absolute Error (MAE): Average of absolute differences
Huber Loss: Combines MSE and MAE

For Binary Classification:
Binary Cross-Entropy: negative of [y times log(y_pred) plus (1 minus y) times log(1 minus y_pred)]
Also called: Log Loss

For Multi-class Classification:
Categorical Cross-Entropy: negative sum of (yi times log of y_pred_i)
Use with: Softmax activation

Backpropagation

Algorithm:
1. Forward pass: Calculate predictions
2. Calculate loss
3. Backward pass: Calculate gradients using chain rule
4. Update weights: w = w minus learning_rate times gradient

Chain Rule:
Partial derivative of Loss with respect to w1 equals partial derivative of Loss with respect to y times partial derivative of y with respect to z times partial derivative of z with respect to w1

Key concept: Gradients flow backward through network

Optimization Algorithms

Gradient Descent:
Update: w = w minus learning_rate times gradient of Loss
Learning rate: Step size parameter
Problem: Can be slow

Stochastic Gradient Descent (SGD):
Uses: One sample per update
Pros: Fast, can escape local minima
Cons: Noisy updates, oscillation

Mini-batch Gradient Descent:
Uses: Batch of samples (32, 64, 128, 256)
Sweet spot: Balance between speed and stability
Most common: Batch size 32

Momentum:
Formula: velocity = beta times velocity plus learning_rate times gradient; w = w minus velocity
Beta: Momentum coefficient (typically 0.9)
Effect: Smooths updates, accelerates convergence
Advantage: Faster in relevant directions

Adam (Adaptive Moment Estimation):
Combines: Momentum plus adaptive learning rates
Hyperparameters: learning_rate equals 0.001, beta1 equals 0.9, beta2 equals 0.999
Most popular: Default choice for many problems
Advantages: Fast convergence, little tuning needed

RMSprop:
Adaptive learning rate per parameter
Good for: Recurrent neural networks
Hyperparameter: Decay rate (typically 0.9)

Regularization Techniques

Dropout
During training: Randomly drop neurons (p equals 0.5 typical)
During inference: Use all neurons, scale by keep probability
Effect: Prevents co-adaptation of neurons
Result: Better generalization

Early Stopping
Monitor: Validation loss during training
Stop when: Validation loss stops improving
Patience: Number of epochs to wait (for example 5 to 10)
Advantage: Simple, effective

L2 Regularization (Weight Decay)
Add penalty: Loss equals Original_Loss plus lambda times sum of squared weights
Effect: Keeps weights small
Lambda: Regularization strength (0.001, 0.01)

Batch Normalization
Normalizes: Inputs to each layer
Formula: x_normalized = (x minus mean) divided by square root of (variance plus epsilon)
Benefits: Faster training, less sensitive to initialization
Placement: After linear transformation, before activation

Data Augmentation
For images:
Rotation: plus or minus 15 degrees
Flipping: Horizontal or vertical
Cropping: Random crops
Color jittering: Brightness, contrast
Noise injection: Gaussian noise

For text:
Synonym replacement
Random insertion or deletion
Back translation

Convolutional Neural Networks (CNN)

Architecture
Typical structure: Conv then ReLU then Pool then Conv then ReLU then Pool then Fully Connected then Output

Convolutional Layer
Filters or Kernels: Small matrices (3x3, 5x5)
Operation: Slide filter across input, compute dot product
Parameters: Number of filters, filter size, stride, padding
Output: Feature map

Example:
Input: 28x28x1 image
Filter: 5x5x1, 32 filters
Output: 24x24x32 (without padding)

Pooling Layer
Max Pooling:
Operation: Take maximum value in each window
Common: 2x2 with stride 2
Effect: Reduces spatial dimensions by 50%
Advantage: Translation invariance

Average Pooling:
Operation: Take average value
Less common: Usually max pooling preferred

Popular CNN Architectures

LeNet-5 (1998):
Layers: Conv-Pool-Conv-Pool-FC-FC
Use: Digit recognition (MNIST)
Parameters: approximately 60,000

AlexNet (2012):
Depth: 8 layers
Innovation: ReLU, dropout, data augmentation
Parameters: approximately 60 million

VGG-16 (2014):
Depth: 16 layers
Design: Uniform 3x3 filters
Parameters: approximately 138 million

ResNet (2015):
Innovation: Skip connections (residual learning)
Depths: 18, 34, 50, 101, 152 layers
Solution: Vanishing gradient problem

Recurrent Neural Networks (RNN)

Basic RNN
Structure:
Hidden state: h_t = f(W_hh times h at time t minus 1 plus W_xh times x_t)
Output: y_t = W_hy times h_t
Key: Same weights used at each time step

Problems:
Vanishing gradient: Hard to learn long-term dependencies
Exploding gradient: Gradients grow exponentially

Long Short-Term Memory (LSTM)
Components:
1. Forget gate: Decides what to forget from cell state
2. Input gate: Decides what new information to store
3. Output gate: Decides what to output

Advantages:
Learns long-term dependencies
Solves vanishing gradient problem
Most popular RNN variant

Gated Recurrent Unit (GRU)
Simplified LSTM: Fewer parameters
Gates: Reset gate, update gate
Performance: Similar to LSTM but faster

Applications
Language modeling
Machine translation
Speech recognition
Time series forecasting
Video analysis

Training Best Practices

Weight Initialization
Xavier or Glorot: For sigmoid or tanh
He initialization: For ReLU
Random uniform: Avoid symmetry breaking

Learning Rate Schedule
Strategies:
1. Step decay: Reduce by factor every N epochs
2. Exponential decay: lr = lr0 times e to the negative kt
3. Cosine annealing: Smooth cyclic schedule
4. ReduceLROnPlateau: Reduce when metric plateaus

Batch Size Selection
Small (1 to 32): More noise, better generalization
Medium (32 to 128): Good balance (most common)
Large (256 plus): Faster training, may hurt generalization

Monitoring Training
Watch for:
Training loss decreasing: Model is learning
Validation loss not decreasing: Overfitting
Loss is NaN: Learning rate too high
Loss oscillating: Learning rate too high

Hardware Acceleration

GPUs (Graphics Processing Units)
Advantage: Parallel matrix operations
Speedup: 10 to 100 times faster than CPU
Popular: NVIDIA Tesla, RTX series
Framework: CUDA for NVIDIA

TPUs (Tensor Processing Units)
Google's custom hardware
Optimized: Matrix multiplications
Available: Google Cloud Platform
Speed: Faster than GPUs for large models

Common Issues and Solutions

Problem: Overfitting
Solutions:
Add dropout
Reduce model complexity
Get more training data
Add regularization
Use data augmentation

Problem: Underfitting
Solutions:
Increase model capacity
Train longer
Reduce regularization
Add features

Problem: Slow convergence
Solutions:
Increase learning rate
Use Adam optimizer
Add batch normalization
Better weight initialization

Problem: Vanishing gradients
Solutions:
Use ReLU activation
Use skip connections (ResNet)
Use LSTM or GRU for sequences
Batch normalization

Problem: Exploding gradients
Solutions:
Gradient clipping
Lower learning rate
Better weight initialization
